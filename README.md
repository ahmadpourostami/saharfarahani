# قالب وردپرس سحر فراهانی

قالب شخصی و آموزشی **سحر فراهانی** برای معرفی و فروش دوره‌های بازیگری، فن بیان، تئاتر و سینما.

## امکانات اصلی

- طراحی RTL و Mobile First
- برند شخصی سحر فراهانی، بدون ساختار چندمدرسی
- اتصال مستقیم به **Tutor LMS**
- نمایش دسته‌بندی‌های دوره به همراه دوره‌های هر دسته در صفحه اصلی
- نمایش جدیدترین دوره‌های Tutor LMS
- صفحه آرشیو اختصاصی دوره‌ها
- کنترل محتوای صفحه اصلی از WordPress Customizer
- بخش اختصاصی پیشخوان برای مدیریت مسیر «اگر می‌خواهید بازیگر شوید»
- برای هر مرحله مسیر: تصویر، عنوان، توضیح، متن دکمه و لینک
- کنترل متن‌ها، تصاویر، لینک‌ها، رنگ‌ها و تعداد آیتم‌ها از Customizer
- پشتیبانی از Custom Logo و WordPress Navigation Menus
- استفاده از تصویر شاخص دوره و تصویر دسته‌بندی Tutor LMS
- سازگار با RTL و نمایش واکنش‌گرا

## تنظیمات

### سفارشی‌سازی
از مسیر **نمایش ← سفارشی‌سازی ← صفحه اصلی سحر فراهانی** می‌توان Hero، درباره من، دسته‌بندی دوره‌ها، جدیدترین دوره‌ها، مسیر یادگیری، CTA، فوتر، رنگ‌ها و عرض محتوا را مدیریت کرد.

### مسیر یادگیری
از مسیر **نمایش ← صفحه اصلی سحر** شش مرحله قابل تنظیم است. هر مرحله می‌تواند تصویر، عنوان، توضیح، متن دکمه و لینک اختصاصی داشته باشد.

## Tutor LMS

قالب دوره‌ها را از پست‌تایپ `tutor_course` می‌خواند و taxonomy `course-category` را برای دسته‌بندی‌های Tutor LMS استفاده می‌کند. برای قیمت دوره از فیلتر `get_tutor_course_price` استفاده شده است.

برای عملکرد کامل بخش دوره‌ها، افزونه Tutor LMS باید فعال باشد.

## نصب

1. پوشه قالب را داخل `wp-content/themes/` قرار دهید.
2. قالب **Sahar Farahani** را فعال کنید.
3. Tutor LMS را نصب و فعال کنید.
4. از Customizer محتوای صفحه اصلی را تنظیم کنید.
5. برای مسیر یادگیری از **نمایش ← صفحه اصلی سحر** استفاده کنید.
6. منوی اصلی و فوتر را از **نمایش ← فهرست‌ها** تنظیم کنید.
