# قالب وردپرس سحر فراهانی

قالب شخصی و آموزشی **سحر فراهانی** برای معرفی و فروش دوره‌های بازیگری، فن بیان، تئاتر و سینما.

## ساختار پروژه

ساختار پروژه عمداً شبیه ساختار واقعی `wp-content` نگه داشته شده است:

```text
wp-content/
├── themes/
│   └── saharfarahani/
└── plugins/
    └── saharfarahani-core/
```

### معماری

این پروژه به‌صورت **Theme + Companion Core Plugin** ساخته شده است:

- `themes/saharfarahani` → ظاهر، قالب‌ها، UI و استایل‌ها
- `plugins/saharfarahani-core` → محتوای اختصاصی و قابلیت‌هایی که نباید به Theme وابسته بمانند
- Tutor LMS → مدیریت دوره‌ها و محتوای آموزشی

## امکانات اصلی

- طراحی RTL و Mobile First
- برند شخصی سحر فراهانی، بدون ساختار چندمدرسی
- اتصال مستقیم به Tutor LMS
- نمایش دسته‌بندی‌های دوره به همراه دوره‌های هر دسته در صفحه اصلی
- نمایش جدیدترین دوره‌های Tutor LMS با استفاده از API/Model داخلی Tutor در صورت وجود
- صفحه آرشیو اختصاصی دوره‌ها
- کنترل محتوای صفحه اصلی از WordPress Customizer
- مسیر یادگیری به‌صورت **Custom Post Type** با تعداد نامحدود مرحله و ترتیب مستقل
- نظرات هنرجویان به‌صورت **Custom Post Type** با قابلیت افزودن، ویرایش، حذف و مرتب‌سازی
- تصویر شاخص برای مراحل مسیر و نظرات
- پشتیبانی از Custom Logo و WordPress Navigation Menus
- سازگار با RTL و نمایش واکنش‌گرا
- فوتر به‌صورت **Block Template Part** قابل ویرایش از ادیتور وردپرس

## مسیر یادگیری

پس از فعال‌سازی افزونه **Sahar Farahani Core**، در پیشخوان منوی **مسیر یادگیری** ایجاد می‌شود.

هر مرحله شامل:

- عنوان
- تصویر / آیکن
- توضیح کوتاه
- متن دکمه
- لینک دکمه
- ترتیب نمایش

برای ترتیب، از فیلد «ترتیب» استفاده می‌شود. بنابراین اضافه یا حذف کردن یک مرحله، ترتیب مراحل دیگر را خراب نمی‌کند.

## نظرات هنرجویان

در پیشخوان منوی **نظرات هنرجویان** ایجاد می‌شود. هر نظر یک نوشته مستقل است و شامل:

- نام هنرجو (عنوان)
- متن نظر
- سمت / توضیح کوتاه
- تصویر هنرجو
- ترتیب نمایش

## فوتر

قالب به‌صورت Hybrid از قابلیت Block Template Parts وردپرس استفاده می‌کند. فوتر در مسیر:

**نمایش ← ویرایشگر ← الگوها ← بخش‌های قالب ← فوتر سایت**

قابل ویرایش است و تغییرات آن در کل سایت اعمال می‌شود.

این روش برای فوتر بهتر از یک Pattern معمولی است؛ Pattern برای درج و کپی یک طرح مناسب است، اما Template Part برای یک بخش سراسری مثل فوتر انتخاب درست‌تری است.

## Tutor LMS

قالب دسته‌بندی‌های `course-category` را از Tutor LMS می‌خواند. برای بخش جدیدترین دوره‌ها، افزونه Core در صورت موجود بودن `Tutor\\Models\\CourseModel::get_courses()` از Model داخلی Tutor استفاده می‌کند و سپس دوره‌ها را بر اساس تاریخ انتشار مرتب می‌کند.

برای عملکرد کامل بخش دوره‌ها، Tutor LMS باید فعال باشد.

## نصب

این repository ساختار `wp-content` را شبیه‌سازی می‌کند. برای نصب:

1. پوشه `themes/saharfarahani` را داخل `wp-content/themes/` قرار دهید.
2. قالب **Sahar Farahani** را فعال کنید.
3. پوشه `plugins/saharfarahani-core` را داخل `wp-content/plugins/` قرار دهید.
4. افزونه **Sahar Farahani Core** را فعال کنید.
5. Tutor LMS را نصب و فعال کنید.
6. از Customizer محتوای صفحه اصلی را تنظیم کنید.
7. مسیر یادگیری را از منوی **مسیر یادگیری** مدیریت کنید.
8. نظرات را از منوی **نظرات هنرجویان** مدیریت کنید.
9. فوتر را از **نمایش ← ویرایشگر ← الگوها ← بخش‌های قالب** ویرایش کنید.

در فعال‌سازی افزونه، اطلاعات قدیمی مسیر یادگیری و سه نظر ذخیره‌شده در Customizer به ساختار جدید منتقل می‌شوند تا محتوای فعلی از بین نرود.
